# Terraformで学ぶAWS

ソースコードのリポジトリ

## サンプルの使い方

利用するサンプルに `terraform.tfvars.example` がある場合は、同じディレクトリに `terraform.tfvars` という名前でコピーし、値を自分の環境に合わせて編集してください。
