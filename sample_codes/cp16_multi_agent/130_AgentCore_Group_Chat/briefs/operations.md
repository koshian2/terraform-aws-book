# 店舗運営メモ

週末のピークは2名体制で、1名はレジ、1名はドリンクと盛り付けを兼務します。
ピーク中は注文ごとの加熱工程を追加できません。オーブンはありません。
季節商品の追加盛り付けは30秒以内を目標にしますが、まだ実測していません。

生果実を注文後に切って扇状に並べる作業は、過去の類似作業では約70秒でした。今回も同じ時間とは限りません。
既存のヨーグルトカップに小分け済みのトッピングを載せる方式なら作業を減らせそうです。
開店前の仕込みに追加できる時間は20分、冷蔵庫の空きは小型トレー1枚分です。
事前に切った果実や解凍品の保持時間・衛生手順は責任者の確認が必要です。味と盛り付け速度も試作で確認してください。
