# 同梱画像の出典と作成方法

`data/receipts/01.png`〜`04.png`は、文字・金額・発行者を架空の内容にして独自に描画した画像です。全画像に「サンプル・架空」を記載しています。`05.png`は重複確認用に`01.png`をそのまま複製しています。`data/preview.png`は4種類の一覧です。

以下の公開例はレイアウトの参考にしたもので、公開画像や実在のロゴ・連絡先を転載したものではありません。

- [Smart EX：購入履歴・領収書](https://smart-ex.jp/en/reservation/reserve_smart/purchase_history/)：利用区間・購入日・支払い方法を項目別に示す横長の構成。
- [ISP：領収書解析のサンプル](https://www.isp21.co.jp/solution/receipt/)：宿泊期間・泊数・単価を含むホテルの明細表。
- [スマレジ：販売レシート](https://help.smaregi.jp/hc/ja/articles/360043637213-%E8%B2%A9%E5%A3%B2%E3%83%AC%E3%82%B7%E3%83%BC%E3%83%88%E3%82%92%E5%8D%B0%E5%88%B7%E3%81%99%E3%82%8B)：商品行、数量・単価、合計、内税、預り金とお釣りの配置。

`data/expected.json`は同梱画像の記載内容とサンプルの分類ルールに対応する検算用データです。実在の取引データは含みません。
