# サンプル会社の分類ルール

| 記載・用途 | 科目 | 扱い |
|---|---|---|
| 鉄道の乗車代 | 旅費交通費 | confirmed |
| 宿泊代 | 宿泊費 | confirmed |
| 文具 | 消耗品費 | confirmed |
| 飲食代、用途不明 | 空欄 | needs_confirmation。用途を質問 |
| 飲食代、取引先との打ち合わせと回答済み | 会議費 | confirmed |
| 私用と回答済み | 空欄 | excluded |

飲食店名や時刻だけで会議費と決めない。他の用途でルールが足りない場合は確認を続ける。
重複候補は duplicate_pending、利用者が重複と確認したコピーは duplicate とする。原本側は通常の分類を保持する。
これらの状態と分類は業務上の整理であり、アクセス制御ではない。
