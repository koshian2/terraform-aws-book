# 経費明細の整理

[分類ルール](references/categories.md)を読んで分類し、[出力仕様](references/output.md)に従って成果物を保存する。

画像を読み取り、元ファイル名・領収書番号・日付・店名・金額を明細に対応付ける。サービス名と発行者の両方がある場合、merchantには領収書の発行者を採用する。読み取れない値を推測で確定しない。
画像読み取り結果のimage_sha256が同じものは、バイト単位で同一画像なので重複候補とする。番号の読み取り揺れで別取引と判断しない。ハッシュが異なる場合も、同じ店名・領収書番号・日付・金額なら重複候補とする。候補は明細に残し、二重計上せず利用者に確認する。確認後も元画像との対応を保持する。
用途不足や重複は、先に暫定成果物を保存してからまとめて質問する。利用者の回答を受けたら状態・分類・確認事項・集計を更新する。
計算はコードで行い、状態別の件数と計上額を検算する。これはサンプルの経費分類であり、正式な複式簿記・税務判定・支払処理は行わない。
