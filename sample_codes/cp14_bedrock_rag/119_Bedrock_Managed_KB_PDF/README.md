# Managed Knowledge BaseでPDFの図表を検索して答える

国土交通省の資料「移住・二地域居住等の促進に向けた検討の方向性について」を、全10ページの原本PDFのまま取り込むサンプルです。図表の項目名・数値・関係が検索テキストに残るか、その根拠から回答できるかを確認します。

## 構成

- `terraform/`: 文書用S3、PDFとメタデータ、専用IAMロール、Managed Knowledge Base、データソース。
- `scripts/`: 取り込み、検索、回答生成のクライアントと共通処理。
- `documents/`: PDFの配置先と出典メタデータ。PDFは公式サイトから取得します。
- `commands.sh`: 準備から実行、片付けまでのコマンド。
- `SOURCES.md`: 資料の出典と利用上の注意。

Smart Parsingと画像抽出を有効にし、埋め込みとリランキングはサービスの管理機能を使います。PythonクライアントはRetrieveで検索し、取得したテキストをConverseへ渡します。回答モデルにはPDFや画像を直接渡しません。

## 実行

Python 3.14、uv、Terraform 1.12以上2.0未満、curl、AWSの認証情報が必要です。AWSプロバイダーは6.66.0に固定しています。設定は `terraform/variables.tf` にまとめ、既定はプロファイル `develop`、リージョン `ap-northeast-1`、回答モデル `jp.anthropic.claude-sonnet-4-6` です。実行者にはリソースの作成・取り込み・検索・モデル呼び出しの権限が必要です。

このディレクトリで `commands.sh` のコマンドを順に実行してください。各処理の成功を確認してから次へ進みます。WindowsではGit Bashを利用し、uv・Terraform・curlがPATHから見つかる状態にします。

TerraformがPDFとメタデータをS3へ配置し、`sync` がKBへの取り込みを開始します。取り込み完了まで最大900秒待ちます。待機が切れてもAWS側の処理は続いている場合があります。同期統計の文書数はPDFファイル単位なので、この例では1件です。

`retrieve` は検索結果を表示し、`ask` はその結果から回答を生成します。既定の質問は円グラフの関心層27.9%の内訳です。検索件数は `--top-k` で1〜20件（既定5件）、リランキングは `--reranking NONE` で無効にできます。検索・回答の生レスポンスは `results/` に保存します。

## 結果の確認

PDF5ページ目（紙面番号4）の円グラフと、PDF6ページ目（紙面番号5）の分類図を開き、検索結果のラベル・数値・単位・関係を照合してください。次に回答の資料ID `[R1]` などを検索結果と照合します。抽出テキストには誤読が含まれる場合があり、スコアは正解確率ではありません。資料は当時の調査・推計であり、現在の実績を示すものではありません。

テキストのない検索結果は生レスポンスに保存しますが、回答生成には使いません。PDFには文字情報も含まれるため、正答だけで画像解析が使われたとは判断できません。

片付け用コマンドは `commands.sh` の末尾にあります。KB・取り込みデータ・文書用S3・専用IAMを削除します。S3に追加したオブジェクトも削除されます。データソースの削除には数分かかる場合があります。ローカルのPDFと実行結果は残ります。
